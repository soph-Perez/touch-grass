## Getting Started

### 1. Clone the Repository

Open VS Code and find the tab **Terminal → New Terminal**.

Run the following command in your terminal:

```bash
git clone https://github.com/soph-Perez/touch-grass.git
```

### 2. Navigate Into the Project

```bash
cd mruhacks2026
```

### 3. Install Dependencies (if installed, skip this step)

```bash
npm install
```

### 4. Create Your Own Feature Branch

**DO NOT PUSH TO MAIN.**

Create a branch using your name and the feature you're working on:

```bash
git checkout -b added-maps-miguel
```

Replace `added-maps-miguel` with your own branch name.

### 5. Start the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the application.

### Important

- Always work on your own feature branch.
- Do not commit or push directly to `main` PLEASE.
- Before starting work, make sure you're on your own branch by running:

```bash
git branch
```

The current branch will have an asterisk (`*`) beside its name.
